# 🎡 Cinema-Tisch · Community-Shortlist

Die Wunschliste für das Glücksrad im Filmpodcast **Cinema-Tisch** von Max & Vincent.

Hier schlagen Hörer:innen Filme vor und voten ihre Favoriten hoch. Die Liste aktualisiert sich live für alle.

## So funktioniert's

- **Film vorschlagen:** Beim Tippen erscheinen passende Filme mit Cover. Steht ein Film schon auf der Liste, wird er direkt angezeigt, und man kann ihn stattdessen hochvoten.
- **Hochvoten:** Pro Film gibt es eine Stimme, die man jederzeit zurücknehmen kann. Die Top 3 bekommen ein Krönchen.
- **Kein Account nötig:** Abstimmen geht anonym, ohne Anmeldung und ohne E-Mail-Adresse.
- **Prüfung:** Vorschläge ohne Treffer in der Filmdatenbank prüfen wir, bevor sie auf der Liste erscheinen.
- **Schon besprochen?** Filme, die schon im Podcast dran waren, werden erkannt und auf die passende Folge verlinkt.

## Technik

Die Seite besteht aus einer einzigen Datei (`shortlist_index.html`) und wird über GitHub Pages ausgeliefert.

- **Daten, Live-Updates und Anmeldung:** [Supabase](https://supabase.com)
- **Filmdaten und Cover:** [TMDB](https://www.themoviedb.org)
